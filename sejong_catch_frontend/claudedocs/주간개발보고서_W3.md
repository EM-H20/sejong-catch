### 🏗️ **아키텍처 인프라 구축**

#### 1. Riverpod 상태 관리 체계
```dart
// 🔥 새로운 패턴: @riverpod 어노테이션 기반
@riverpod
class OnboardingController extends _$OnboardingController {
  @override
  OnboardingState build() => const OnboardingState();

  // 상태 변경은 copyWith로 불변성 보장
  void nextStep() {
    state = state.copyWith(currentStep: state.currentStep + 1);
  }
}

// 일반 Dart 클래스로 상태 정의 (Freezed 대신)
class OnboardingState {
  final int currentStep;
  final bool isCompleted;

  const OnboardingState({
    this.currentStep = 0,
    this.isCompleted = false,
  });

  OnboardingState copyWith({
    int? currentStep,
    bool? isCompleted,
  }) {
    return OnboardingState(
      currentStep: currentStep ?? this.currentStep,
      isCompleted: isCompleted ?? this.isCompleted,
    );
  }
}
```

### **Q1. 상태 관리 라이브러리 - "Provider, Bloc, GetX 등 많은데 왜 Riverpod인가요?"**

**🎯 답변 포인트:**
- **컴파일 타임 안전성**: Provider는 런타임 에러 가능성, Riverpod은 컴파일 시점 타입 검증
- **보일러플레이트 감소**: @riverpod 어노테이션으로 50% 코드 감소
- **성능 최적화**: 필요한 위젯만 리빌드 (Provider는 전체 서브트리 리빌드)
- **Flutter 팀 공식 추천**: Google이 차세대 상태 관리로 권장
- **팀 조언**: 시니어 개발자의 실제 프로덕션 경험 기반 권장

```dart
// 기존 Provider vs 새로운 Riverpod 코드 비교
// ❌ Provider: 수동 알림, context 의존
// ✅ Riverpod: 자동 리빌드, context 독립, 타입 안전
```

### **Q2. 라우팅 - "Navigator 2.0, AutoRoute 등 있는데 왜 GoRouter인가요?"**

**🎯 답변 포인트:**
- **Flutter 팀 공식 패키지**: Google 직접 개발/유지보수 보장
- **선언적 라우팅**: URL 기반으로 직관적이고 웹 배포 시 SEO 친화적
- **내장 라우트 가드**: 권한 기반 리다이렉트 기능 기본 제공
- **ShellRoute 지원**: BottomNavigationBar 유지하면서 페이지 전환
- **타입 안전성**: 경로 파라미터 컴파일 타임 검증

```dart
String? authGuard(BuildContext context, GoRouterState state) {
  final user = context.read(authControllerProvider).user;

  if (protectedPaths.contains(state.location)) {
    if (user == null || user.role == UserRole.guest) return '/auth';
  }

  if (operatorPaths.contains(state.location)) {
    if (user?.role.index < UserRole.operator.index) return '/unauthorized';
  }

  return null; // 접근 허용
}
```

### **Q5. 세종대 SSO 연동 플로우**

**🎯 인증 아키텍처:**
```
📱 Flutter → 🐍 Python Auth → 🏫 세종대 포털 → 🟢 Node.js → 📱 Flutter
      (학번/비밀번호)     (SSO 인증)        (토큰 교환)    (인증완료)
```

**🔐 보안 설계:**
- **이중 토큰**: sejong_token(5분) → access/refresh 토큰(1시간/7일)
- **자동 갱신**: Dio Interceptor로 401 에러 시 토큰 자동 리프레시
- **안전한 저장**: FlutterSecureStorage (키체인/키스토어)
- **HTTPS 통신**: 모든 API 호출 암호화
